# CODSOFT Python Programming Internship

A collection of Python command-line applications developed during my CODSOFT Python Programming Internship.

## Projects

### 1. Simple Calculator
File: `simple_calculator.py`

- Addition, subtraction, multiplication, and division
- Numeric input validation
- Division-by-zero protection
- Reusable functions

### 2. To-Do List
File: `to_do_list.py`

- View, add, delete, and complete tasks
- Duplicate and empty-task validation
- Persistent local storage using a text file
- Modular functions for each operation

### 3. Contact Book
File: `contact_book.py`

- Add, view, search, update, and delete contacts
- Search by name or phone number
- Persistent JSON storage
- Input validation and safe file handling

## Technologies Used

- Python 3
- Functions and modular programming
- Lists and dictionaries
- File handling and JSON
- Exception handling
- Command-line interface (CLI)

## How to Run

Make sure Python 3 is installed, then run any project from the repository folder:

```bash
python simple_calculator.py
python to_do_list.py
python contact_book.py
```

The To-Do List creates `tasks.txt` automatically. The Contact Book creates `contacts.json` automatically.
